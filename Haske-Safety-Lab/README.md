# Haske Safety Lab

## Project Title
Robustness of Lightweight Machine-Learning Models for Scam SMS Detection in Hausa and English.

## Project Overview
This project explores lightweight machine-learning methods for identifying potentially suspicious SMS messages, with a focus on English and Hausa language contexts.

## Model
Linear Support Vector Classifier (LinearSVC) with character n-gram TF-IDF features.

## Prototype
The Streamlit application is intended to demonstrate SMS classification and explain potential warning signs.

## Research Status
This is a research prototype. Its predictions are not guaranteed to be correct and should not be treated as proof that a message is safe or fraudulent.
